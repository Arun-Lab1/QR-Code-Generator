# QR Code Generator 📱

QR Code Generator is a clean, lightweight Python application built with Kivy that lets you turn URLs or text into scannable QR codes and export them directly as PDF documents. Designed to be fast and straightforward, it helps you create and save QR codes without bloated dependencies.

Whether you need a quick link QR code or a ready-to-share PDF file, QR Code Generator keeps the workflow simple and easy to run directly from Python.

## ✨ Key Features

* **Instant QR Generation** — Enter any URL or text string and generate a crisp QR code in seconds.
* **Direct PDF Export** — Exports your generated QR code directly as a `.pdf` file (`QRCode_<timestamp>.pdf`) using `Pillow`.
* **Clear On-Screen Feedback** — Displays real-time status updates and error messages right in the app interface.
* **Clean Temp File Handling** — Automatically cleans up temporary `temp_qr.png` files when you close the app.
